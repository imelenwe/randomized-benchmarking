Phase 0 · Setup

Decide the target and the training range (θJ,θx,θy) not (delta,J,hx,hy); box = [−1,1]³, checked 3 independent ways. Written up in analysis/index.html.
Phase 1 · Data generation
Write the joint sweep function Draws (θJ,θx,θy) uniformly from the box per run, calls couple_with_env(1.0, J=θJ, hx=θx, hy=θy) directly — delta fixed at 1, so the 3 drawn numbers ARE the physical unknowns, no separate delta involved. next
Smoke test — a handful of runs ~10–20 runs, eyeball the parquet output and confirm features extract cleanly, before committing hours of compute.
Kick off the full generation run Background, resumable, checkpointed per-file like the original sweep. Run count: to confirm.

Phase 3 · Validation (the actual deliverable)
Aggregate metrics per parameter Reuse sbi_eval.py's report() — RMSE + calibration, called once per parameter.
Recoverability map across the whole box Not just one test point — check for RB-blind corners (commuting-limit regions flagged in the literature scan) where the model would converge to a meaningless answer.
Bimodality / mode-recovery check Coverage alone won't catch a split (sign-ambiguous) posterior — cluster each test example's samples and flag when they separate into two groups.
Worked-example posterior plots "Here's the input, here's the sampled cloud, here's the truth" — a few chosen cases, including one near the anomaly's own strength (θ≈0.4–0.7).
