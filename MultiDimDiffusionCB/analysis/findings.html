Findings — joint (θJ, θx, θy) diffusion inference

The "pick up from here" doc. For the full narrative with data tables, see index.html; for the live checklist, see plan.html. This page is the crisp summary of what changed this session and what to do next.

TL;DR — the joint diffusion model (θJ, θx, θy from raw CB data) is built, trained, and working — but only after finding and fixing a real physics limitation, not a bug: raw CB data encodes coupling magnitude, not sign. Retargeting the model from signed theta to |theta| fixed it (val MSE 0.21 → 0.06–0.09). Phase 0–2 on plan.html is done; Phase 3 (validation) hasn't formally started.

What's built (Phase 0–2, done)

  • code/joint_sweep.py — generates CB data for random (θJ, θx, θy) triples via couple_with_env. Already run once: 10,000 files sit in code/data/ (gitignored, regenerable via run_joint_datagen.py).
  • code/joint_sbi_experiments.ipynb — the full pipeline: load_joint_features (parquet → 36 features → tensors) → NoisePredictor (the network) → train_joint_diffusion (training loop) → sample_joint_posterior (reverse-diffusion sampling → posterior clouds).
  • Trained model (5000 epochs) gets val MSE ≈ 0.058, still improving — more epochs help (cheap, ~1 min for 5000 epochs); more training data does not (diminishing returns already hit at ~4000 rows).

The sign problem (the main finding)

What we found: correlation between the 36 raw CB features and signed theta_J/x/y is ~0.02 (noise) across all 10,000 runs. Correlation with |theta_J| (magnitude) is up to 0.65. The features are symmetric in theta's sign — the environment qubit is never measured directly, so its role in fixing the sign is invisible to CB.

What it's called in the literature

Verified citations, not guessed — fetched and cross-checked, not recalled from memory:

  • Sone & Cappellaro, Hamiltonian identifiability assisted by a single-probe measurement, Phys. Rev. A 95, 022335 (2017), arXiv:1609.09446 — some couplings from a single accessible probe are identifiable only up to sign.
  • Burgarth & Yuasa, Quantum System Identification, Phys. Rev. Lett. 108, 080502 (2012), arXiv:1104.0583 — without full state access, a Hamiltonian is identifiable only up to unitary conjugation.

The fix applied

load_joint_features now returns y = np.abs(theta_J, theta_x, theta_y) instead of signed values — range [0,1], not [-1,1]. Predictions now track true magnitude well (e.g. true theta_J=0.757 → predicted 0.76). Full before/after tables are in index.html §5.

what this means for the original goal

Explaining λXX=0.42 on ibm_fez: likely fine. λXX itself is built from the same kind of sign-blind statistics, so a magnitude-only theta estimate should be enough to test "is a coupling of about this strength consistent with the observed anomaly." What it can't do is hand back a fully-signed Hamiltonian for combining with other mechanisms elsewhere on the chip — that needs a different measurement, not a better model on this same data.

Cross-axis leakage (secondary finding, smaller effect)

Separate question: does theta_x's true value leak into theta_J's predicted value (not a sign issue — a magnitude-confusion issue)? Checked directly:

checkresultreading
off-diagonal error correlation (e.g. theta_J error vs. true theta_x)-0.11 to -0.14small — no major cross-axis confusion
diagonal error correlation (theta_J error vs. true theta_J)-0.43 to -0.54ordinary regression-to-mean shrinkage, not confusion
per-axis R²J: 0.79, x: 0.74, y: 0.97theta_y recovered especially well

Verified mathematically (not just empirically): commuting Hamiltonian terms (e.g. theta_y=0, X-type only) give zero leakage by construction — shifting theta_x by a fixed amount moves the same eigenvalue by exactly the same amount regardless of theta_J. With theta_y genuinely nonzero (the real, non-commuting case), the same shift in theta_x moves the eigenvalue by a different amount depending on theta_J (0.35 → 0.39 → 0.40) — leakage is real, structurally enabled by non-commuting terms, but current data shows it's a soft, secondary effect, not dominant. Unlike sign, this is not an exact symmetry — more/better data can likely reduce it further.

Why theta_y is recovered so much better (solved, verified)

An earlier pass at this (single-feature correlation, then a linear "fainter signal" story) was wrong on both counts and was removed from this doc. Here is the version that's actually verified end to end.

Step 1 — build an independent first-principles replica. Wrote a from-scratch simulator of the exact real pipeline (same Hamiltonian, same m_list=(2,4,6,8,12,16), same 30-twirl averaging, same theta-draw mixture) and generated 1,500 synthetic runs with the theoretical (infinite-shot, zero sampling noise) value of every feature. It reproduced the real data almost exactly — best single-feature correlation 0.643/0.632/0.970 for J/x/y (real data: 0.65/ 0.64/0.97), same top features (mean_Y6/Y4 for J and x, mean_X2/X4 for y). This proves the asymmetry is pure structural physics, not shot noise or a training artifact.

Step 2 — look at the actual shape of the curve. Binning runs by |theta_J| and averaging the feature mean_Y6 in each bin: it starts at only 0.77 (not near 1) with high spread (std≈0.28) even at the smallest theta_J, then goes completely flat by theta_J≈0.33 and stays flat out to 0.9 — the top half of the range carries almost no signal. mean_X2 vs. theta_y, by contrast, starts at 0.998 with almost no spread (std≈0.002) and decays smoothly and monotonically across the whole range. Something is adding noise and causing early saturation specifically on theta_J's channel.

Step 3 — find the contaminant. Held theta_x near zero (|theta_x| < 0.05) and recomputed theta_J's correlation with mean_Y6: it jumped from -0.643 to -0.949 — almost theta_y's own cleanliness. Symmetric check confirms it: holding theta_J near zero moves theta_x's correlation with the same feature from -0.627 to -0.918. Meanwhile theta_y's correlation with its own feature (mean_X2) barely moves whether theta_J/theta_x are free or held at zero (-0.970 vs. -0.950) — nothing was ever contaminating it.

the mechanism

theta_J and theta_x share one observable channel and contaminate each other; theta_y has an exclusive channel that neither of them touches. theta_J's generator (X⊗X) and theta_x's generator (X⊗I+I⊗X) commute with each other (verified by direct diagonalization), so their effects combine into one shared "X-type" signature that shows up on the same Pauli-Y/Z survival-probability features. Whatever the other one happens to be doing shows up as noise and early saturation in that shared channel. theta_y's generator (Y⊗I+I⊗Y) doesn't commute with either of the other two, so it drives a separate channel (Pauli-X survival) that's entirely its own — nothing else writes over it, so it comes through nearly noise-free.

Literature scan: is there something better than CB?

Looked for alternatives that could recover more than CB does (verified via web search and direct paper fetch, not guessed):

  • Two-qubit joint/simultaneous readout + process tomography (PRL 102, 200402; PRX Quantum 1, 010305) — the most promising concrete lever. The sign-blindness theorems above assume the environment is never measured. In our setup "the environment" is a real, individually addressable superconducting qubit, not a true inaccessible bath — so this assumption is a choice inherited from the original 1-D design, not a law of physics. Measuring both qubits (not marginalizing over the second) is a well-established real capability and directly targets the mechanism that causes sign loss.
  • Process Tensor Tomography (PRX Quantum 3, 020344) and the Transfer Tensor Method — generalize CB/RB to capture non-Markovian memory more fully. Worth reading if the two-qubit route doesn't pan out.
  • Optimal Ansatz-free Hamiltonian Learning In Situ, PRX Quantum 6, 040315 (2025) — recent, prestigious, but ancilla-free/control-free like CB; doesn't obviously solve the sign problem either.
  • Efficiently learning non-Markovian noise in many-body quantum simulators, arXiv:2511.16772 (Nov 2025) — read in full: single-probe, no-ancilla protocol for many-body lattice simulators, Gaussian-noise assumption, classical (non-ML) estimator. Different scale and goal from this project; doesn't address sign ambiguity. Useful only as evidence this is a live, current (2025) research area, not a ready-made fix.
recommendation

Don't pivot away from CB. Extend it — test whether raw joint two-qubit measurement outcomes (both qubits, not just the system qubit with the environment traced out) break the sign symmetry, using the existing harness (couple_with_env already builds the 2-qubit unitary; measure_P currently discards qubit 2's outcome). Small, testable, targeted experiment before considering a bigger pivot.

Is any of this publishable?

Yes, as-is, independent of anything further: a rigorous, numerically verified demonstration of a known-but-rarely-empirically-confirmed Hamiltonian identifiability limit (Sone & Cappellaro; Burgarth & Yuasa), inside a concrete SBI/diffusion-model pipeline on realistic CB data, with hard numbers (not just the abstract theorem). Worth bringing to the next Friday-7PM meeting as a real result, not a stall.
