Core engine

cb_harness.py — the silent engine

No drivers, no rendered plots — definitions only, imported via from cb_harness import *. Everything downstream ultimately comes from here.

  • CBConfig — the dataclass holding every knob (qubit counts, shots, m_list, L twirls, K Pauli subsampling), including the two fields that DEFINE a noise class: env_coupling_gate + reset_env.
  • couple_with_env(delta, J=1.7, hx=1.47, hy=-1.05) — builds the S+E Hamiltonian from the PRX non-Markovian RB paper, returns U_SE = exp(-i·delta·H). The physics core of memory and jitter.
  • make_drift(eps) — just RXGate(eps), drift's coherent over-rotation, no environment qubit.
  • noise_knobs(noise_class, param) — the one function mapping a class name to its CBConfig knobs. Read this to see the three classes side by side.
  • apply_dressed / build_real_circuit — builds the dressed CB circuit (twirl → cycle → env coupling → optional reset, repeated m times).
  • lambda_from_records — the 2-point λP estimator: lambda_P = (F[m2]/F[m1])^(1/(m2-m1)), endpoints only, not a full curve fit.
  • records_to_dataframe — flattens nested run records into the long-format table every downstream notebook reads.
  • sweep() vs sweep_for_diffusion() — two different data-generation functions for two different datasets. See the Data Pipeline page.

run_diffusiondatagen.py

CLI driver for data_diffusion/. python run_diffusiondatagen.py 2000 runs sweep_for_diffusion for the memory class only, δ ~ U[0.02, 0.25]. Resumable (skips existing parquet files by filename). SBI pipeline modules

These four exist specifically so the Gaussian net and diffusion model are compared honestly — same data loader, same eval harness, swappable estimator.

sbi_data.py — parquet → model input

One function: load_features(data_dir, test_frac=0.2, seed=0). Reads every parquet in data_dir, computes mean + variance of f_pml over the 30 twirls per (Pauli, m) → 36 features per run, splits train/test on a fixed seed, and standardizes features using train-set statistics only (no leakage into test).

gaussian_net.py — the control model

GaussianNet: a 3-layer MLP, 36 → 128 → 128 → 2, splitting output into (μ, σ) via softplus for σ. gaussian_nll is the loss — its derivation is in the file's own comment block, worth reading; it shows Gaussian NLL collapses to plain MSE when σ is frozen. train_gaussian selects weights by validation NLL, not train NLL — train-NLL selection rewards overconfidence.

conditional_diffusion.py — the estimator

Four pieces, in build order: noise_lookup(T) (cosine schedule → alpha/alpha_bar tables), add_noise(x_0, t, alpha_bar) (the fixed forward jump), NoisePredictor (MLP taking x_t, a sinusoidal time embedding of t, and the 36-feature condition c → predicted noise), train_diffusion (noise-regression training, same val-loss discipline as the Gaussian net), and sample_posterior_inference (the 100-step reverse walk turning one condition into 1000 posterior samples). The module docstring carries the formula card in Lnv's own notation — read it before the code.

sbi_eval.py — the shared harness

One function, report(mu, sigma, y, title), used identically by both models. Prints RMSE, NLL, ±1σ/±2σ coverage, std of z, fraction |z|>2 — and plots predicted-vs-true plus a residual-calibration histogram against N(0,1). If you're checking whether a claimed result is apples-to-apples, check both models called this same function on the same test rows.

Driver notebooks

generate_cb_data.ipynb — Phase-0 gate + all 3 classes + data/

Ten cells. Cell 2 is the Phase-0 gate check: runs the harness against known Markovian noise models and confirms measured λP matches the analytic oracle. Don't trust anything else in the repo until this cell's numbers look right on a fresh environment. Cells 3–5 run one example of each class and plot its decay curve. Cell 8 is the real data-generation driver: sweep() across memory/jitter (4 δ dials) and drift (7 ε dials, wider), 30 seeds each → the 450 files in data/.

analyze_noise_separability.ipynb — Step 5, the discriminability study

Seven cells. Where the project's central finding lives. Cell 3 (5a) plots the averaged view — what standard CB actually sees, the null result. Cells 4–5 (5b) plot Varl(f) vs m for memory vs jitter, raw then shot-noise-floor-subtracted — the money plot. Cell 6 extends to all three classes at a data-driven matched decay level, and is where the X-channel-stays-flat-for-drift cross-Pauli fingerprint falls out.

baseline_classifier.ipynb — the 88.7% result

Four cells. Loads the same data/ (450 examples), computes one variance-vs-m slope per Pauli per example — 3 features, no λ anywhere — then StandardScaler + LogisticRegression, 5-fold stratified CV. Final cell's output: mean accuracy: 0.887 +/- 0.022 against chance = 0.33.

sbi_experiments.ipynb — Gaussian net vs diffusion

Ten cells, thin by design. Loads data_diffusion/ (10,000 memory-only continuous-δ runs). Cells 4–5 train/evaluate the Gaussian net. Cells 7–8 build/evaluate diffusion — note the δ standardization done inline here, not inside conditional_diffusion.py. A fully-annotated, more heavily commented earlier version of the Gaussian-net build lives only in git history now, at commit 97efa5c, filename SBI_model.ipynb.

Data directories

Both gitignored, both regenerable from the harness with fixed seeds. Full detail on the Data Pipeline page; the short version:

data/

450 parquet files, 243,000 rows. All three noise classes, discrete dial grid. Feeds analyze_noise_separability.ipynb and baseline_classifier.ipynb.

data_diffusion/

10,000 parquet files. Memory class only, continuous δ draws. Feeds sbi_experiments.ipynb only.

These are not the same dataset — a common point of confusion navigating the repo cold. See Decisions and Assumptions for why they're split this way.
learn/

This folder. diffusioncb_presentation.html is the slide deck built for the advisor meeting (also live at the published Artifact link) — a narrative document, distinct in purpose from the reference pages here, which are meant to be read cold, edited, and kept current as the project moves.
