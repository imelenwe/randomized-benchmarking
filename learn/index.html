Benchmarking Study Guide

One front door for everything in this repo, in the order to study it: from plain Randomized Benchmarking, through Cycle Benchmarking on real IBM hardware, to inferring hidden noise with a diffusion model.

How this folder is laid out. explainers/ holds the HTML pages (read in a browser). handwritten-notes/ holds scanned derivations and proofs (PDF). The code itself stays in its own folders (RB/, CB/, DiffusionCB/, MultiDimDiffusionCB/); this page links to it.

Covering the basics

Short statements that look obvious and carry a lot: the Born rule and the trace, projectors versus observables, Kraus operators, and the Lindblad derivation step by step. Each comes with a worked example and a recall question.

Study path

1

Standard RB

Random Clifford sequences of growing length; the survival probability decays as A·pm + B, and p gives the average error per gate. Errors in state preparation and measurement only change A and B, not p.

notebook plan explainer page: to write
2

Interleaved RB

Insert one target gate between the random Cliffords and compare the decay with plain RB, to estimate that single gate's error (as a bound, not an exact value).

notebook plan handwritten derivation (PDF)
3

Cycle Benchmarking

Benchmark one whole cycle of gates using random Pauli gates instead of Cliffords, so it scales to many qubits and gives one fidelity per Pauli. Run on real ibm_fez hardware, where it found the unusual XX decay of 0.42.

notebook plan handwritten proof (PDF) report (PDF) working notes hardware run log
4

The Lindblad equation

The standard equation for noise with no memory. The rest of this guide is about what happens when that "no memory" assumption fails. Background first: how a quantum channel is written down (Choi and Kraus forms) and how tracing out part of a system produces one.

channels: partial trace, Choi to channel (PDF) Lindblad derivation (PDF)
5

Noise with memory: one number

A conditional diffusion model reads raw (un-averaged) CB data and recovers a single coupling strength for noise with memory, which standard CB averages away. The process tensor is the formal way to describe noise with memory; the diffusion notes cover how the model works.

process tensor 1 2 3 4 (general) diffusion models 1 2 explainer pages slide deck slide deck (PDF)
6

Noise with memory: three numbers

The same idea extended to the full two-qubit Hamiltonian: theta_J, theta_x and theta_y together. Finds that only the size of each coupling can be recovered, not its sign, and that theta_J and theta_x blur each other while theta_y comes through clean.
