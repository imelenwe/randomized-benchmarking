How to navigate this codebase

This is the current, evolved picture of DiffusionCB — not the original design. nonmarkovian_cb_diffusion_spec.md (one level up) is the initial spec; its own progress tracker was last updated 2026-07-11 and doesn't cover the classifier, the continuous-δ dataset, the Gaussian net, or the diffusion model — all of which exist in code now. Treat the four pages below as current status.

Read these notebooks, in order
1 generate_cb_data.ipynb Phase-0 gate check, all 3 noise classes side by side, and the driver that builds data/. 2 analyze_noise_separability.ipynb Step 5 — the discriminability study. Where the core finding lives. 3 baseline_classifier.ipynb The 88.7% classifier, reading only raw-data variance slopes. 4 sbi_experiments.ipynb Gaussian net vs conditional diffusion — the δ-recovery result.
TL;DR results: classifier separates the 3 noise classes at 88.7% ± 2.2% (chance 33%) reading only raw-data variance slopes, no λ. Diffusion recovers δ at RMSE 0.0024 vs the Gaussian-net control's 0.0050, with better-calibrated uncertainty (97.2% vs 90.8% within ±2σ, ideal 95%).
