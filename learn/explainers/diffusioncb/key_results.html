generate_cb_data.ipynb · cells 3–5

2. What each noise class looks like, qualitatively

memory (non-Markovian, E carried): bent, non-monotonic decay on a log-y axis. jitter (stochastic-Markovian, E reset each cycle): straight, monotonic decay — memoryless. drift (coherent, no E): decays with a coherent wobble — non-monotonic like memory, but for a completely different reason.

Why it matters: memory and drift can look superficially similar from this view alone — motivating the need for a sharper fingerprint than "does the curve look bent."

3. The core finding — raw data separates what λP can't

At matched parameter (0.10), memory and jitter's λP are barely different — standard CB genuinely cannot tell them apart:

classλXλYλZ
memory0.980.9340.920

Cell 3 (5a): plots this averaged view directly — confirms visually how close the two classes' decay curves sit. "What standard CB sees": a near-null result.

Cells 4–5 (5b, then shot-noise-floor-subtracted): plots Varl(fpml) vs m for the same two classes. Memory's variance grows with m (compounding correlation across cycles); jitter's stays flat (memoryless — averages out). Cell 5 subtracts the binomial shot-noise floor (4·n_plus·n_minus/shots³) and confirms the separation survives.

This is the money plot of the whole project: the exact same λP, a qualitatively different variance-vs-m shape.

4. The cross-Pauli fingerprint — separating drift from memory

Extends the comparison to all three classes, at a data-driven matched decay level (not hardcoded — computed from the actual overlap of each class's achievable decay range; example run: {'drift': 0.4, 'jitter': 0.1, 'memory': 0.1}). Plotted per Pauli.

Finding: drift's variance on the X channel stays essentially flat — a coherent X-rotation commutes with the X Pauli it can't disturb its own axis. Memory disturbs X too. This is the fingerprint that separates the two non-monotonic-looking classes that cell 2's qualitative view alone couldn't.

6. The δ-recovery proof of concept — Gaussian net vs diffusion

Scope: memory class only, δ ∈ [0.02, 0.25], 10,000 runs, one seed=0 train/test split (8,000/2,000), one trained model per method.

Reading it correctly: the Gaussian net was measurably overconfident (std z = 1.22, too many outliers past 2σ). Diffusion's sampled posterior closed that gap and improved point accuracy at the same time. This is honest, scoped evidence within this one experiment — not yet evidence about generalization, multi-parameter targets, or real hardware.

Note the Phase-3 gate comparison this result is actually missing: it was never benchmarked against finding #5's classifier, only against the Gaussian-net control. See Decisions and Assumptions.

Model sizes / training: Gaussian net 21,506 params / 2,000 epochs; diffusion 23,553 params / 5,000 epochs (needed more — training curve still dropping at epoch 1900).
